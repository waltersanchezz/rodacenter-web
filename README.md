# Roda Center

Sitio web desarrollado para la venta de baterías y rodamientos.

## Descripción

Roda Center es un proyecto web enfocado en ofrecer información y atención para la venta de:

- Baterías automotrices
- Rodamientos
- Atención personalizada
- Servicio a domicilio

## Tecnologías utilizadas

- HTML5
- CSS3
- Git
- GitHub

## Estructura del proyecto

```text
rodacenter-web
│
├── index.html
├── baterias.html
├── rodamientos.html
├── styles.css
├── robots.txt
├── sitemap.xml
└── Imagenes_rodacenter
```
